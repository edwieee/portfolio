Agents / Concept brief

Handoff

Work that pauses for a decision.

Intersecting orbits
Study topics
  • Task state
  • Human review
  • Resumption

The question

When a brief changes halfway through a task, which parts of a draft can still be used? This concept explores the point where a person takes a decision back from an agent.

Proposed architecture

Each run would keep its input, draft and checkpoint together. A review screen would show the pending decision. A revision would create a new version tied to the reviewer’s instructions.

First experiment

Interrupt a draft during review, edit its instructions and reopen it in a new session. Verify that resuming selects the reviewed version and preserves the earlier draft.

Proposed flow

  1. Receive brief
  2. Prepare draft
  3. Request review
  4. Resume work
