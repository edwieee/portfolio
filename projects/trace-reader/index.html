Trace Reader

Following a request across services.

Parallel traces
Study topics
  • Tracing
  • Local tooling
  • Observability

The question

A request took five seconds. Was the delay in a service, between services, or in an interval nobody measured? This proposed tool would open an exported trace locally so a developer can follow its timing.

Proposed architecture

A parser would group spans by trace identifier and parent. A timeline would show overlapping calls, with a detail view for durations, attributes and missing parents.

First experiment

Start with one slow child span, a pair of overlapping calls and an incomplete trace. Test whether the display keeps gaps visible and avoids double-counting concurrent work.

Proposed flow

  1. Open export
  2. Group spans
  3. Lay out timing
  4. Inspect gaps
