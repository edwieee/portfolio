Passage Index

Finding the paragraph behind an answer.

Layered passages
Study topics

  • Evaluation

The question

What happens to a citation when a handbook changes? This proposed reader would keep a link between each quoted passage, its file and the edition available when the question was asked.

Proposed architecture

An importer would preserve headings and page boundaries. A retriever would return passages with edition identifiers, giving the reader enough context to inspect a citation beside the answer.

First experiment

Build a small collection with two editions of the same handbook. Ask questions whose answers changed and record when retrieval selects the superseded passage.

Proposed flow

  1. Import editions
  2. Index passages
  3. Retrieve evidence
  4. Inspect citation
