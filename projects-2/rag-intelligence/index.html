Upcoming concept / Document intelligence

RAG Intelligence

An answer with a reading trail.

A document workspace concept for answering questions across a library and opening the passages behind each claim.

Reading brief

When two policy documents disagree, a reader needs to know which edition supports an answer. This concept would connect every answer to the document, page and passage used to construct it.

Planned features

Readers could restrict a question to a collection or edition, compare retrieved passages and inspect citations in context. An unanswered question would show which sources were searched.

Proposed architecture

An importer would preserve headings and page offsets. A retrieval service would combine keyword and semantic search before ranking the passages. A generation step would receive the selected evidence and return references the reader can open.

Illustrated walkthrough

Follow a sample scenario through the proposed system.

Import documents

A collection contains two editions of a travel policy.

Retrieve passages

A question about reimbursement retrieves the allowance table from each edition.

Compose a response

The proposed response would explain which edition applies to the trip date.

Inspect citations

Opening a citation would take the reader directly to that table.
